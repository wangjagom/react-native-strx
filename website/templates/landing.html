Get started

Three steps to your first animation.

STRX sits on top of Reanimated, so setup is the Reanimated setup plus one provider.

Full installation guide →

  1. 01

    Install with Reanimated 4

    npm i react-native-strx react-native-reanimated react-native-worklets

    Expo apps: use npx expo install for the Reanimated packages. Bare apps add react-native-worklets/plugin last in Babel.

  2. 02

    Wrap your app

    import { Strx } from "react-native-strx";

<Strx.Provider motionPreset={{ duration: 300 }}>
  <App />
</Strx.Provider>

    Sets default timing, follows the OS Reduce Motion setting, and connects event timelines.

  3. 03

    Add animate

    <Strx.View animate="fade-in from:translate-y-12 layout-spring">
  <Strx.Text>Hello STRX</Strx.Text>
</Strx.View>

    Every STRX component accepts the same animate prop: View, Text, Pressable, Image, ScrollView, TextInput, and your own via createStrxComponent.

The grammar

Read it like a sentence.

Each token does one thing. Order inside a group doesn't matter, and a comma starts a new group with its own timing.

fade-inPreset
from:translate-y-12Keyframe
exit:opacity-0Exit
transition-colorsStyle transition
layout-springLayout
duration-400Timing
ease-outEasing

fade-in, slide-up duration-500

Two groups play together. duration-500 applies to slide-up only.

bounce spring damping-12

Switch to the spring driver and tune it inline with damping, stiffness and mass.

from:opacity-0 to:opacity-100 play-infinite

Write keyframes directly when no preset fits, and loop them with play-*.

Beyond entrances

Every kind of motion, same prop.

Style transitions

Changes to style animate from the value on screen, so toggling mid-way never jumps.

<Strx.View animate="transition-all duration-300"
  style={{ width: on ? 200 : 120 }} />
Transitions →

Layout

Size and position changes spring into place. Children inherit it; components without a token pay nothing.

<Strx.View animate="layout-spring" layoutClip>
Layout transitions →

Timelines

Choreograph targets in parallel, serial or stagger. stop() freezes in place, reverse() continues from there.

<Strx.Timeline playback="stagger" interval={100}>
